# Sika — GiveWP Payment Gateway for West Africa

**Sika** adds FedaPay and KkiaPay as payment gateways in GiveWP, 
enabling nonprofits and associations in Benin and West Africa 
to accept donations via Mobile Money.

Built by [Norts](https://github.com/norts-bj).

---

## Features

- FedaPay integration for GiveWP
- KkiaPay integration for GiveWP
- Mobile Money support (MTN MoMo, Moov)
- Compatible with GiveWP donation forms

## Requirements

- WordPress 5.8+
- GiveWP 3.x
- FedaPay or KkiaPay account

## Installation

1. Download the plugin zip
2. Upload to `/wp-content/plugins/`
3. Activate in WordPress admin
4. Go to GiveWP → Settings → Payment Gateways
5. Configure your FedaPay/KkiaPay API keys
